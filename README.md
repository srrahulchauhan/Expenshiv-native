# Expenshiv-native

📱 **My Expense Tracker** — A clean, beginner-friendly React Native (Expo) mobile application.

## Features
- **Home Screen**: Total Balance, Income, and Expense summary cards with recent transactions.
- **Transactions Screen**: Search bar with category, note, and amount filters; FlatList table.
- **Summary Screen**: Visual category-wise spending progress bars (Food, Travel, Shopping, Other).
- **Add Transaction**: Clean modal for adding Income / Expense with category picker and date.
- **Offline Storage**: Uses `@react-native-async-storage/async-storage` to persist transactions.

## How to Run

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the project:
   ```bash
   npx expo start
   ```

- Press `w` to open in browser (Web)
- Scan QR code with the **Expo Go** app on Android or Camera app on iOS
